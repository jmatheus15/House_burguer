# House Burguer

Site da hamburgueria House Burguer, de Coremas (PB). HTML, CSS e JavaScript puros, sem build.

- `site/` é a pasta publicada: `index.html` e `assets/`.
- `testes/pedido.test.js` testa a mensagem do pedido no WhatsApp: `node testes/pedido.test.js`.
- `pacote-de-design.md` guarda o texto e as decisões de design.

## Ver no computador

```bash
python -m http.server 8080 --directory site
```

Depois abra http://localhost:8080. O vídeo do topo só roda com servidor; abrindo o `index.html` direto aparece uma foto parada.
